ExamSprint

A smart, urgency-and-confidence-driven study revision planner for university students.

⚡ The Unique Kernel

A deterministic, client-side JavaScript priority engine that weighs days until exam against student confidence level to answer the critical question: "What should I study right now?"

Priority Score = f(Exam Days Remaining, Confidence [Low | Medium | High]) + Plain-English Reasoning

🎯 Proof of Concept Boundary

Click each boundary tier to review what belongs in this sprint:

● NOW (POC Core) — 2 to 4 hour target ▼
  • Add course subjects and revision topics
  • Set exam dates and select student confidence (Low, Medium, High)
  • Client-side JavaScript priority scoring algorithm (instant calculation, zero API costs)
  • Display dynamically sorted revision queue with score badges and plain-language explanations
  • Instant recalculation upon changing confidence or exam dates
  • Mark topics completed to track sprint progress
● LATER (Post-Hackathon) ▼
  • Saving state in browser localStorage across page reloads
  • AI chatbot assistant for personalized topic explanations and flashcard drill
  • User accounts, login, and multi-device cloud synchronization
● CUT (Explicitly Excluded) ▼
  • Email reminders & automated alerts: Cut to avoid background cron schedulers, external mailing services, and backend server complexity during this focused frontend proof of concept.
